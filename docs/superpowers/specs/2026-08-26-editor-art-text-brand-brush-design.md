# 编辑器艺术字、品牌与画笔设计

## Goal

填充编辑器的文字、品牌和画笔面板：文字只展示已同步的创客贴公开艺术字；品牌和画笔提供本地、可保存的编辑能力。

## Scope

- 文字面板保留标题、副标题和正文快捷项，并追加“官网公开艺术字”两列卡片。
- 艺术字只使用本地目录中 `kind: asset`、`sceneId: 459` 的 24 条资源；点击按普通图片图层插入。
- 品牌面板保存当前设计的品牌色列表。颜色选择器可新增颜色；点击色板将颜色应用为画布背景；每个颜色可移除。
- 画笔面板提供颜色、粗细和不透明度控制。启用后在画布空白处拖动创建笔触；撤销、协作、保存和 PNG/JPEG 导出都保留笔触。

## Data Model

- `CanvasDocument` 新增可选 `brandColors: string[]`，新建设计采用一组默认颜色；旧设计缺失该字段时回退到默认颜色。
- `EditorLayer.type` 新增 `brush`。笔触保存为相对于画布的 `points`、颜色、粗细和不透明度；不使用远端 URL、画布位图或浏览器本地存储。
- 解析旧 `canvasJson` 时，未知或缺失的新增字段不影响既有文字、图片和形状图层。

## Interaction

- 画笔模式下，画布空白区域接收 pointer 事件并在 pointer up 时一次性提交笔触图层；只读分享链接保持不可编辑提示。
- 笔触以不可直接拖拽的 SVG/路径预览显示，避免与既有图层选择和移动手势冲突。
- 普通模式保持现有的图层选择、拖动、缩放和图片插入行为。

## Export And Collaboration

- `renderDocumentToDataUrl` 使用 Canvas 的圆角线段绘制笔触，确保预览、保存和导出结果一致。
- 协作桥继续同步完整 `CanvasDocument`；接收远端更新时采用现有合并路径，因此品牌色和笔触随文档更新。

## Non-Goals

- 不读取创客贴登录态、品牌库、收藏、团队资源或任何私有接口。
- 不伪造官网品牌或画笔数据，也不把艺术字声明为可编辑原始文字。
- 本次不实现橡皮擦、笔刷纹理、压感或多页面共用品牌库。

## Verification

- 添加回归测试，覆盖艺术字筛选、品牌色的持久化回退、笔触图层的保存/导出分支、只读保护和工具面板结构。
- 运行聚焦测试、完整前端测试、lint、生产构建、changed-file review 和仓库质量门禁。
- 使用已有已登录设计或开发预览夹具进行浏览器验证：艺术字卡片显示 24 项，品牌色可添加/移除，笔触可撤销并出现在导出文件中。

## Risk

- 笔触点数会增加 `canvasJson` 大小；通过在 pointer move 时进行采样并仅在一次笔触结束后提交，限制更新频率和保存压力。
- 艺术字是公开预览快照，许可证或可编辑性变化仍需要在显式同步时复核。
