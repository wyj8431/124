# 官方目录模板创建设计

## 目标

点击“创建设计”弹窗中的官方目录模板后，编辑器应显示所选模板的本地封面图，而不是空白画布。

## 范围

- 前端继续从 `/create-design/official/catalog.json` 读取官方目录。
- 创建请求携带所选模板的 `templateId`、`templateTitle`、`templateCoverUrl`、宽度和高度。
- 复用后端现有的官方模板兜底逻辑，将封面写为第一张图片图层。

## 非目标

- 不把官方目录模板导入本地 `design_template` 数据表。
- 不拆分模板封面为独立可编辑文字或图形图层。
- 不修改编辑器画布渲染、数据库结构或模板同步脚本。

## 验收标准

1. 选择 ID 为 `582997` 的官方目录模板时，创建请求包含该 ID 和它的本地 `coverPath`。
2. 返回的设计画布包含封面图片层，编辑器不再只显示白色空画布。
3. 现有的自定义尺寸创建流程保持空白画布行为。
