# 编辑器图片编辑面板切换设计

## 目标

用户在编辑器左侧“图片”素材面板点击任一图片、上传图片或提交图片 URL 后，新增图片会被选中，左侧同一工具面板立即从图片素材列表切换为“图片编辑”面板。关闭该面板或取消图片选中后，恢复图片素材列表。

## 交互

- 切换条件是 `activeTool === 'image'` 且当前选中图层的类型为 `image`。
- 图片编辑面板的关闭按钮只取消图层选中，不关闭整个左侧工具栏。
- “替换图片”打开已有图片文件选择器，并替换当前图层，不新增图层。
- “设为背景”把当前图片铺满画布并移至所有图层之后。
- 滤镜、调整和裁剪控件实时更新当前图片；图层仍可在画布上拖动和缩放。
- 图片效果写入 `CanvasDocument`，保存、撤销和导出均沿用已有文档流。

## 范围

- 提供可生效的滤镜预设、亮度/对比度/饱和度/模糊调整、裁剪区域、透明度、圆角、描边、投影、翻转和图层顺序。
- “AI 抠图”复用已存在的浏览器端人物分割模块；无法读取跨域图片时显示明确错误，不伪造处理结果。
- 不新增尚无模型或服务端能力的 AI 消除、扩图、高清、局部重绘功能。

## 验收

1. 从左侧图片素材添加一张图片后，左侧显示“图片编辑”及替换图片、设为背景和工具网格。
2. 关闭图片编辑后，左侧重新显示上传、URL、搜索和图片分组。
3. 调整滤镜或裁剪后，画布和 PNG/JPEG 导出呈现相同效果。
4. 无图片选中、只读分享和非图片图层均不进入图片编辑模式。
