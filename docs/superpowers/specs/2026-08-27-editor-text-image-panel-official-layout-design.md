# 编辑器文字与图片官网式面板设计

## 目标

按照用户提供的官网编辑器截图，重做“文字”和“图片”工具的侧栏信息层次。文字面板应先提供快捷创作，再呈现艺术字分组；图片面板应先提供上传和链接入口，再提供搜索、标签和横向分组图库。

## 用户可见结构

### 文字

1. 搜索框位于面板顶端。
2. 搜索框下方为“标题”“副标题”“正文”“竖排文字”“特效文字”五个快捷文字动作，以及可进入现有 AI 工具的“AI 文案”横幅。
3. 艺术字按“变形标题”“特效文字”“节日热点”“国风主题”“热门文字”分组。每组默认显示三张无可见标题的缩略图，右侧“全部”只展开当前组，并可“收起”。

### 图片

1. 顶部保留现有“上传图片”和“粘贴图片地址”能力。
2. 上传区之后显示“搜索图片”输入框和可切换的“春天”“科技”“教育”“美食”“背景”“旅行”标签。
3. 图片按“春日灵感”“科技创意”“教育阅读”“美食旅行”“图片背景”“插画精选”分组。默认使用横向预览条展示前三张卡片，“全部”展开为两列网格。
4. 搜索和标签共同筛选本地分组；没有命中时显示明确空状态。

## 架构与边界

- `TextResourcePanel` 继续拥有搜索与展开状态，并增加快捷文字和 AI 入口回调。
- 新增 `ImageResourcePanel`，负责图片搜索、标签筛选、分组展示和单组展开；受控的上传、URL 输入和插入回调继续由 `DesignEditorPage` 持有。
- `DesignEditorPage` 从本地 `OfficialResource` 构造稳定的关键词分组。图片面板排除 `sceneId: 459` 的艺术字，背景素材在图片面板中按普通图片层插入；背景工具自身的“设为背景”流程不变。
- 不新增运行时官网请求，不修改 `CanvasDocument`、图层存储、上传 API、撤销或保存逻辑。

## 验收标准

- 文字工具同时出现搜索、五个快捷动作、AI 文案入口和艺术字分组。
- 图片工具同时出现上传、链接、搜索、标签和分组缩略图；图片面板中不出现艺术字场景。
- 两个面板的卡片点击均复用已有插入函数；文字快捷动作创建文字图层，上传和图片 URL 继续工作。
- 搜索无结果时有空态；“全部”只展开所点击的一个分组。
- 900px 宽度下，文字卡片为三列，图片展开网格为两列，侧栏仍可见。
