# 外部模板编辑器初始画布设计

## 目标

首页展示的官方模板可能只存在于前端官方目录，本地 `design_template` 表没有对应记录。点击这类模板创建副本后，设计页必须显示用户刚刚选择的模板，而不是空白画布。

## 方案

- 本地模板继续直接复用数据库中的 `canvasJson`，行为不变。
- 对本地不存在、但请求携带模板标题和封面地址的官方模板，后端创建用户设计时生成一个与画布同尺寸的 `image` 图层，图层 `src` 使用官方封面地址，位置为 `(0, 0)`，尺寸覆盖整个画布。
- 封面图层仍属于普通图片图层，因此可由现有编辑器选中、移动、缩放、删除和保存。
- 官方目录当前只提供封面资源，没有完整的文本、形状和图片元素 JSON；本次不伪造不可获得的可编辑元素。

## 数据流和边界

1. 首页点击模板时继续提交 `templateId`、标题、封面、宽高。
2. `DesignService.create` 先查询本地模板。
3. 查询不到且请求包含非空模板标题时，使用正数宽高（缺失时回退到 `800x600`）生成初始画布。
4. 封面为空时仍创建空画布，避免把无效 URL 写入 JSON。
5. 本地模板、场景创建、空白设计、保存和权限校验不改变。

## 验收标准

- 外部模板创建请求保存的 `canvasJson.layers` 至少包含一张 `type=image` 图层。
- 该图层的 `src` 等于请求封面 URL，`x/y` 为 `0`，宽高等于画布宽高。
- 没有封面 URL 时不会生成包含 `null` 的 JSON。
- 后端 `DesignServiceTest` 通过，前端现有构建和编辑器图片图层渲染保持通过。

## 风险与非目标

- 官方 CDN 地址可能过期；本次不下载、代理或刷新官方素材。
- 这是一张合并后的封面图片，不承诺官方模板内部文字和元素可分别编辑。
