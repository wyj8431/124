# 首页 AI 模式五栏内容设计

## 目标

首页切换到 Agent、图片生成或视频生成模式后，均展示官网采集的五个 AI 灵感栏目；当前模式关联的栏目组排在首位。

## 方案

- `frontend/src/data/chuangkitHomeAiModesOfficial.ts` 是唯一的栏目数据来源。
- 固定栏目为：小红书封面、营销海报、亚马逊套图、商品详情页、短剧带货。
- Agent 模式先展示小红书封面、营销海报；图片生成模式先展示亚马逊套图、商品详情页；视频生成模式先展示短剧带货。
- `HomePage` 仅根据当前模式读取该数据映射，并将每个栏目交给既有 `TopicScrollSection` 渲染。模板模式保持原有首页内容，不进入 AI 栏目分支。

## 交互和容错

- 用户切换模式时清空当前搜索状态，避免搜索结果覆盖新模式栏目。
- 未知模式映射为空列表，不渲染错误内容。
- 图片加载失败仍由既有栏目卡片的默认行为处理；本次不新增接口、状态或资源依赖。

## 验收和测试

- 三个 AI 模式均含五个唯一栏目，且模式优先顺序符合上述规则。
- 首页将模式变化传入该映射，并只在 AI 模式时渲染该映射的栏目。
- 新增 Node 测试保护数据与页面接线，随后执行前端测试、`npm run build`；仓库未提供 `scripts/quality-gate.ps1`，该项将记录为无法执行。

## 风险

本次只补充前端静态内容与回归保护，远程图片资源仍依赖官网 CDN 的可用性。
