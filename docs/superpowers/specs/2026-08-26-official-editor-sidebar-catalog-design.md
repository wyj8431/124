# 官网目录侧栏增强设计

## 目标

将设计编辑器左侧栏增强为接近创客贴公开编辑器的“工具入口 + 素材目录”结构。用户可以在不离开编辑器的情况下浏览已同步的公开分类、搜索素材目录，并把已保存到项目中的封面图添加到画布。

## 现状和数据边界

- `DesignEditorPage` 已有与参考界面一致的工具入口：添加、我的、模板、素材、文字、图片、背景、组件、AI 工具、画笔、团队。
- `frontend/public/create-design/official/catalog.json` 是项目已有的本地目录快照，当前含 13 个分类、265 个场景和 312 个模板记录。
- `frontend/scripts/sync-create-design-catalog.mjs` 通过公开接口更新该快照及其本地封面资源。应用运行时不得请求、解析或执行 `www.chuangkit.com` 页面与脚本。
- 本次仅使用已经在项目内的目录元数据和封面文件；不获取登录态数据、不下载原站新文件、不绕过访问限制。

## 方案

### 左侧工具栏

保留现有 11 个工具入口及其现有功能，避免改变已经接近参考界面的工作流。新增一个“品牌”入口，提供当前画布可复用的颜色快捷项和品牌资源占位状态；它不新增后端接口或持久化模型。

### 素材目录面板

“素材”面板保留搜索框、素材类型标签和基础元素快捷项。其下新增“官网公开目录”区域：

1. 展示本地快照中的一级分类，包括海报、抖音/小红书、微信、电商、PPT、印刷/办公、H5、社交生活、视频和插画元素。
2. 点击一级分类后显示该分类的场景卡片与模板封面卡片；默认展示“精选推荐”。
3. 搜索匹配模板标题、场景名称和一级分类名称。搜索为空时保留当前分类筛选。
4. 点击场景卡片创建与目录记录一致尺寸的新画布；点击模板封面卡片将已保存的封面图作为普通图片图层添加到当前画布。
5. 对没有本地可用图标或封面的记录使用名称和固定占位样式，卡片仍可被搜索和筛选；不发起网络补图请求。

### 模板和品牌面板

“模板”入口改为复用同一目录的模板封面和分类筛选，避免与“素材”面板各维护一份素材清单。“品牌”入口仅提供画布颜色快捷项和空状态，确保入口点击后存在可用内容，而不是展示无效按钮。

## 数据流

```text
公开同步脚本（开发时手动运行）
  -> catalog.json + public/create-design/official 下的本地资源
  -> 编辑器目录加载器
  -> 素材 / 模板 / 品牌侧栏面板
  -> 场景改尺寸或封面图添加为普通图片图层
```

目录加载失败时，编辑器继续使用当前内置 `EDITOR_ASSETS` 和基础工具，不阻塞画布编辑、保存、导出或协作。

## 组件边界

- 新建一个目录加载与筛选模块，负责解析本地 `catalog.json`、生成可展示的场景与模板项，并验证本地路径格式。
- `DesignEditorPage` 只维护选中分类、搜索词和用户动作；它通过模块得到可渲染项目，继续调用现有画布操作函数。
- `index.css` 为目录卡片、分类切换和缺图占位增加紧凑的响应式样式，遵循现有编辑器的 Figma 风格 token。
- 不修改后端、数据库、鉴权、外部 API 契约或现有官方同步脚本的下载策略。

## 错误处理和可访问性

- 本地目录读取失败时显示简短的回退提示，仍展示内置素材。
- 目录图像加载失败时使用文字占位，图片元素的 `alt` 使用对应标题。
- 分类、类型标签和搜索结果使用语义按钮与 `aria-pressed` 或既有 tab 语义，键盘可聚焦。
- 卡片数量限制为当前分类的首批结果，以保持侧栏滚动性能；搜索只在内存中对已加载目录执行。

## 验收标准

- 素材面板展示来自本地目录的一级分类与精选内容，且浏览器网络请求不包含 `chuangkit.com`。
- 可按分类和关键词筛选本地场景与模板；无结果时显示明确空状态。
- 点击场景会更新画布尺寸，点击模板封面会创建可选中、可移动、可删除的普通图片图层。
- 原有内置素材、上传、文本、背景、组件、AI、画笔和团队面板不回归。
- 目录读取失败时仍可使用原有内置素材和编辑器主流程。
- 新增聚焦的 Node 回归测试，前端类型检查、lint、测试和生产构建通过。

## 非目标和风险

- 不承诺将来源模板拆分为可编辑文字、形状和图片；封面仅作为一张图片图层使用。
- 不实现官网账号、素材购买、版权授权、远端素材收藏或定时爬取。
- 本地目录是快照，内容更新需要开发者显式运行现有同步脚本并审核变更。
- 本地封面可能因历史同步缺失；此时使用名称占位，不将失败伪装成可用媒体。
