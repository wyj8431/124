# 编辑器公开资源面板同步设计

## 状态与目标

本设计已获确认。它扩展已有的官网目录快照，使编辑器的资源型侧栏面板可以在存在稳定、公开且可复核的官网目录时使用本地同步的数据。目标是丰富模板、素材、图片、背景、组件和画笔面板，同时保持编辑器运行时离线、快速且不依赖第三方登录态。

本设计在 `2026-08-26-official-editor-sidebar-catalog-design.md` 已有模板/素材目录功能的基础上增量完成，不替换现有画布、上传、协作或品牌功能。

## 范围与数据边界

### 允许的来源

- 仅在开发者手动或 CI 显式触发同步时，请求创客贴可匿名访问的公开元数据和公开媒体资源。
- 已验证的目录和模板来源包括：
  - `contentcopyright/page/module/create/design/kinds?nottrans=true`
  - `team/distribution/template/centerQuery.do`
  - 公开设计索引页所使用的分类接口，例如 `team/distribution/template/firstKinds.do`。
- 每个新增资源适配器必须先通过契约探测：响应无需 Cookie/账号，包含稳定标识、标题和可公开下载的预览资源，且与面板语义相符。

### 明确禁止

- 编辑器运行时不得访问 `chuangkit.com`、`gw.chuangkit.com` 或原站 CDN。
- 不使用账号、Cookie、授权头、付费资源、用户设计、团队数据或任何规避访问限制的方法。
- 不实现定时爬取、远端收藏、购买、版权授权或将官方模板拆成可编辑图层。

### 面板归属

| 面板 | 数据策略 |
| --- | --- |
| 模板 | 使用公开分类、场景和模板预览的本地快照。 |
| 素材、图片 | 使用已验证的公开元素或图片目录；没有适配器时保留现有内置素材。 |
| 背景 | 仅在存在独立公开背景目录时同步；否则保留颜色选择器和内置色板。 |
| 组件 | 仅接入可安全映射为基础图形或可下载预览的公开目录；否则保留矩形与圆形。 |
| 画笔 | 仅在存在公开、可复用的笔刷预览目录时同步；否则保留现有入口，不伪造同步结果。 |
| 添加、我的、文字、品牌、AI 工具、团队 | 始终保持本地或用户/组织工作流，不参与官网同步。 |

## 架构与数据流

```text
公开官网目录
  -> 开发时同步脚本中的受控适配器
  -> 响应与媒体校验、限量下载、失败项过滤
  -> frontend/public/create-design/official 下的版本化 catalog.json 和资源文件
  -> officialCatalog 本地加载器的路径/字段校验
  -> 编辑器模板、素材、图片、背景、组件、画笔面板
```

同步器只在所有写入完成后原子替换目录索引。上一次成功的索引和资源始终是可用回退，不因一次网络或单项资源失败被覆盖。

目录格式从当前的分类、场景和模板结构扩展为向后兼容的公开资源集合。每一项至少包含：稳定 `id`、`title`、`kind`、本地预览路径、来源分类和必要的尺寸/显示元数据。资源路径必须位于 `/create-design/official/` 的受支持子目录内；加载器会丢弃未知字段、无效 ID、空标题和越界路径。

资源适配器以面板类型隔离：模板目录不依赖素材目录，素材目录不依赖背景目录。无法证明公开、稳定或语义匹配的类型不创建适配器，也不产生空白的“官方”区域。

## 编辑器行为

- 模板面板继续按分类和关键词浏览；点击场景沿用当前的新画布尺寸行为，点击模板预览沿用当前插入本地封面图片图层的行为。
- 素材和图片面板合并展示当前内置内容与已同步的公开内容。搜索与分类只在已加载的本地索引内执行。
- 公开图片和素材点击后会创建可选中、拖动、缩放和删除的图片图层，绝不保存官网远端 URL。
- 若同步到合格的背景预览，点击会插入一个铺满画布、置于其他图层下方的本地图片图层；现有背景色控件保持可用。
- 若同步到可映射的基础组件，点击会创建现有可编辑的形状图层；不能映射为基础图形的条目只作为普通预览素材处理，避免宣称为可编辑组件。
- 画笔没有验证通过的公开目录时维持当前提示和本地入口；验证通过后再显示对应的本地预览和动作。
- 本地目录加载失败、某一面板没有可用资源或某次同步跳过某项时，编辑器继续展示既有内置控件，并给出简短、非阻塞的回退提示。

## 错误处理与可访问性

- 同步请求失败、响应码不成功、业务码非成功、字段不完整、资源 MIME 类型未知或下载重试耗尽时，记录该项并跳过；不会清空上一份成功索引。
- 资源下载只接受允许的图像类型，并用响应头、魔数或规范化扩展名决定本地扩展名。
- 所有卡片和筛选入口保持语义按钮、键盘可聚焦状态和可读标签；缩略图的替代文本使用资源标题。无缩略图时显示名称占位，不进行运行时补图。
- UI 不将来源资源标记为用户已购买、已授权或可编辑原件。

## 验证策略与验收标准

### 自动化测试

- 为同步器增加公开响应解析、类型适配、目录路径白名单、资源 MIME/扩展名识别、单项下载失败和保留上次成功目录的单元测试。
- 为本地加载器增加旧版索引兼容、扩展资源记录、无效字段过滤和未知资源目录拒绝测试。
- 为编辑器增加聚焦测试：模板/素材/图片插入、公开背景置底、基础组件创建，以及目录不可用时内置工具仍可操作。

### 手工与构建验证

- 运行一次显式同步并检查产物只含本地路径；随后在浏览器网络面板确认编辑器未向官网域名请求资源。
- 在桌面和窄视口检查侧栏搜索、分类、空状态、缩略图失败占位以及文字不溢出。
- 执行相关前端测试、生产构建、`node scripts/codex-code-review.mjs --scope changed-files --format json` 和 `pwsh -File scripts/quality-gate.ps1`，处理本次变更导致的高、中优先级问题。

## 风险与非目标

- 官网公开接口可能改版或收回匿名访问。同步器必须失败可见、运行时继续可用，并通过适配器隔离影响范围。
- 同步的是可公开访问的预览和元数据快照，不保证其为可编辑源文件，也不改变原资源的许可或归属。
- 本次不修改后端、数据库、鉴权、用户上传、团队资源或 AI 业务契约。
