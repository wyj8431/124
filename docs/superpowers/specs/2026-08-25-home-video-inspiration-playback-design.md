# 首页视频灵感播放设计

## 目标

让首页视频生成模式的“短剧带货”官网灵感卡片可以预览和播放对应的官方 MP4，而非只显示不可点击的封面。

## 方案

- 继续使用 `chuangkitHomeAiModesOfficial.ts` 作为首页官网灵感的唯一数据来源。
- 在 `HomeSectionCard` 上增加可选 `videoUrl`；只有“短剧带货”卡片填充该字段，地址来自现有 `aiVideoInspirationMedia.ts` 的官方签名 MP4 映射。
- `TopicScrollSection` 检测到 `videoUrl` 时渲染静音、循环、内联的原生视频预览，并在点击后通过回调把卡片交给页面。
- `HomePage` 复用已有 `AiCreationDetailModal`，将首页卡片适配为专题灵感条目，在点击后打开详情播放器。非视频卡片保持现有的模板创建操作。

## 容错与边界

- 视频预览无法自动播放时，封面仍会显示；点击后的详情页使用同一 MP4 地址。
- 外部 MP4 为带签名的官网 CDN 地址，到期后需要通过既有采集脚本刷新。本次不下载、代理或伪造官网资源。
- AI Provider 未配置导致的“生成结果没有视频”属于另一个后端环境问题，不在本次范围内。

## 验收

- 视频生成模式的“短剧带货”每张卡都携带官方 MP4 地址。
- 该卡片有视频元素和点击播放详情；图片灵感仍保留模板点击路径。
- 用 Node 回归测试、前端 lint/build 和浏览器播放检查验证。
