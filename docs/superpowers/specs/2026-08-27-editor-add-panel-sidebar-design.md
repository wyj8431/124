# 编辑器添加面板与侧边栏对齐设计

## 目标

以用户提供的官网编辑器截图为视觉参考，调整设计编辑器的“添加”面板和左侧工具栏。保持当前本地资源、上传、图层、保存、撤销及导出链路不变。

## 用户可见结构

### 添加面板

1. 使用图片/视频、文字、形状、组件、工具五个分区，并在每个分区右上角提供“更多”入口。
2. 图片/视频提供本地上传、手机上传；文字提供标题、副标题、正文、竖排文字、特效文字。
3. 形状提供矩形、三角形、圆形、圆角矩形、直角三角形、星形。点击后应插入与图标一致的图层，并能在浏览器预览和导出图像中一致呈现。
4. 组件与工具卡沿用当前可用入口：组件跳转至组件面板，导入文件触发上传，尺寸延展打开画布属性，模板和 AI 卡分别打开现有对应工具。

### 侧边栏

1. 保留现有工具标签和“品牌”入口，避免移除已有功能。
2. 使用更接近参考图的 Lucide 图标：背景为 `PanelTop`，组件为 `Boxes`，画笔为 `Paintbrush`；其余入口沿用语义匹配的图标。
3. 添加面板使用与文字、图片资源面板相同的宽侧栏轨道；1100px 以下回退至现有紧凑轨道。

## 边界与约束

- 不增加官网运行时请求、外部素材或依赖。
- 只扩展当前本地的图层形状枚举；旧的矩形和圆形文档保持兼容。
- 画布预览与 `renderDocumentToDataUrl` 必须共用形状绘制规则，避免导出形状退化为矩形。
- 不在没有真实会员或授权数据时展示 VIP、限免等状态标签。

## 验收标准

- 添加面板包含五个参考分区及其卡片，且所有卡片存在有效动作。
- 六种形状在画布和导出路径都有一致的绘制契约。
- 侧边栏的背景、组件、画笔图标使用指定图标，其余现有入口未丢失。
- 桌面宽侧栏、1100px 紧凑回退和现有上传、文字、模板、AI 入口可用。
